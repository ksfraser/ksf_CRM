# Use Cases - ksf_Onboarding_UI

---

## UC-ONB-001: View Onboarding Dashboard
**Actor**: HR Manager

**Preconditions**: User has HR access

**Flow**:
1. Navigate to HR > Onboarding Dashboard
2. View summary cards (active hires, pending tasks)
3. View timeline for each hire
4. Click on hire for details

---

## UC-ONB-002: Start New Hire Onboarding
**Actor**: HR Manager

**Preconditions**: Employee record exists

**Flow**:
1. Navigate to HR > New Hire Onboarding
2. Select employee from recruitment
3. Wizard Step 1: Personal info verification
4. Wizard Step 2: Documents (ID, contracts)
5. Wizard Step 3: IT setup tasks
6. Wizard Step 4: Training assignments
7. Wizard Step 5: Team introductions
8. Complete onboarding

---

## UC-ONB-003: Complete Onboarding Task
**Actor**: HR Manager, Manager, New Hire

**Preconditions**: Task assigned to user

**Flow**:
1. Navigate to My Onboarding Tasks
2. View task with checklist
3. Mark items complete
4. Add notes if needed
5. Submit task completion

---

## UC-ONB-004: Upload Onboarding Document
**Actor**: New Hire, HR Manager

**Preconditions**: Onboarding in progress

**Flow**:
1. Navigate to Documents section
2. Click upload or drag-drop file
3. Select document type
4. System validates file
5. File stored, linked to onboarding

---

## UC-ONB-005: Assign Task
**Actor**: HR Manager

**Preconditions**: Task exists, unassigned

**Flow**:
1. Open task details
2. Click Assign button
3. Select user from dropdown
4. Set due date
5. Confirm assignment

---

## UC-ONB-006: Track Progress
**Actor**: HR Manager, Manager

**Preconditions**: Onboarding in progress

**Flow**:
1. View progress ring on dashboard
2. Drill down to see task breakdown
3. Identify overdue tasks
4. Send reminders
5. Adjust timeline if needed
