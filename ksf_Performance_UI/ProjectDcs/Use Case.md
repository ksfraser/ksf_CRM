# Use Cases - ksf_Performance_UI

---

## UC-PERF-001: Create Performance Review
**Actor**: Manager

**Preconditions**: Review cycle open, employee selected

**Flow**:
1. Navigate to HR > Performance > New Review
2. Select employee
3. View employee goals
4. Rate competencies (1-5 scale)
5. Assess goal achievement
6. Add overall rating
7. Write comments
8. Submit for approval

---

## UC-PERF-002: Employee Self-Review
**Actor**: Employee

**Preconditions**: Review cycle open

**Flow**:
1. Navigate to My Performance
2. Open self-review form
3. Self-assess competencies
4. Rate goal achievement
5. Add self-comments
6. Submit self-review
7. Manager notified

---

## UC-PERF-003: Track Goals
**Actor**: Employee, Manager

**Preconditions**: Goals assigned

**Flow**:
1. Navigate to Goal Tracker
2. View assigned goals
3. Update progress percentage
4. Add milestones/completion notes
5. Mark goal complete
6. Manager approves

---

## UC-PERF-004: Calibration Session
**Actor**: HR Manager, Senior Manager

**Preconditions**: Reviews submitted

**Flow**:
1. Navigate to Calibration
2. View rating distribution matrix
3. Identify outliers
4. Drag-drop to adjust ratings
5. Add discussion notes
6. Lock ratings
7. Finalize reviews

---

## UC-PERF-005: View Performance Report
**Actor**: HR Manager, Executive

**Preconditions**: Reviews completed

**Flow**:
1. Navigate to HR > Performance Reports
2. Select report type
3. Choose filters (department, cycle)
4. Generate report
5. Export to PDF/Excel

---

## UC-PERF-006: Competency Assessment
**Actor**: Manager

**Preconditions**: Employee has job description

**Flow**:
1. Open review form
2. View competencies from job description
3. Rate each competency 1-5
4. Add specific examples
5. Save assessment
