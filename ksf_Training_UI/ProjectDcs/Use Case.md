# Use Cases - ksf_Training_UI

---

## UC-TRN-001: Browse Training Catalog
**Actor**: Employee, HR Manager

**Preconditions**: User has access

**Flow**:
1. Navigate to HR > Training
2. Browse available courses
3. Filter by category
4. Search for specific course
5. View course details
6. Enroll in session

---

## UC-TRN-002: Create Training Course
**Actor**: HR Manager, Training Admin

**Preconditions**: Admin access

**Flow**:
1. Navigate to Course Management
2. Click "New Course"
3. Enter course details
4. Add competencies linked
5. Add course materials
6. Create sessions (schedule)
7. Set capacity
8. Publish course

---

## UC-TRN-003: Enroll in Training
**Actor**: Employee

**Preconditions**: Course available, session scheduled

**Flow**:
1. View training catalog
2. Click on course
3. View available sessions
4. Select session
5. Click Enroll
6. Confirmation received
7. Added to calendar

---

## UC-TRN-004: Track Attendance
**Actor**: Instructor, HR Manager

**Preconditions**: Session completed

**Flow**:
1. Navigate to Attendance
2. Select session
3. View enrolled employees
4. Check attendance for each
5. Submit attendance
6. System updates completion status

---

## UC-TRN-005: Submit Training Feedback
**Actor**: Employee

**Preconditions**: Training completed

**Flow**:
1. Navigate to My Training
2. Find completed course
3. Click "Give Feedback"
4. Rate course (1-5)
5. Add comments
6. Submit feedback
7. Feedback visible to admin

---

## UC-TRN-006: Generate Certificate
**Actor**: HR Manager, Employee

**Preconditions**: Training completed, attendance marked

**Flow**:
1. Navigate to completed enrollment
2. Click "Generate Certificate"
3. Preview certificate
4. Download or send to employee
5. Certificate stored in documents

---

## UC-TRN-007: View Competency Gap
**Actor**: Manager, Employee

**Preconditions**: Competency profiles exist

**Flow**:
1. Navigate to Competency Gap
2. Select employee
3. View required vs current competencies
4. See training recommendations
5. Enroll in gap courses
6. Track progress
